Добавлены три заданных тестовых файла: 8 сценариев guard (A1–A7 и beforeunload),

## 2. Отступления и противоречия

- Дополнительно замокан `usersApi.requestAdminUser`: эффект страницы вызывает
  `fetchAdminUser`, чей pending очищает предзагруженную карточку. Одного
  preloadedState недостаточно. Компоненты и slice не изменены.
- В двух новых файлах используется настоящий Node AbortController через
  `node:util.transferableAbortController`, с восстановлением globals после
  suite. Node Request отвергал сигнал jsdom при реальном переходе router.
  Навигация, useBlocker и beforeunload не замоканы.
- A7 трактуется как продолжение уже заблокированного перехода при `when=false`.
  Текущее `blocker.reset()` закрывает диалог, но отменяет переход. Проверка не
  ослаблена до одного исчезновения диалога и не помечена skip/expected failure.
- Требование prompt «Change: nothing» конфликтует с обязательным новым отчётом;
  вне трёх тестовых файлов добавлен только этот отчёт.
- Prompt исключает ручной checklist, AGENTS.md §§8–9 требует его и имеет
  приоритет. Минимальный checklist оставлен в разделе 6.
- ТЗ 18.3 содержит историческую запись «срез 14 не выполняется», тогда как
  текущий prompt задаёт slice 14 с тестами. Состав функциональности и заявление
  о непроверенном WCAG не менялись; запись ТЗ оставлена для решения автора.

## 3. Блокер

A7 падает: после `/form` → `/elsewhere`, открытия диалога и смены локального
состояния harness с true на false диалог исчезает, но заголовок «Другая
страница» не появляется. Остаётся «Форма». Причина в
`client/src/routes/UnsavedChangesGuard.tsx`: stale-block effect вызывает reset.
Компонент запрещено менять заданием. Для зелёного gate нужно отдельное решение
о поведении A7 либо разрешённое исправление компонента.

Коммит не создан: AGENTS.md запрещает коммит при проваленном обязательном gate.
Тесты и отчёт оставлены в рабочем дереве для рассмотрения дефекта.

## 4. Вне области изменений

более 500 kB. Это не ошибки сборки. Исходный untracked
