# Срез 12 — клиентская часть

## Выполнено

1. В `statisticsFormat.ts` добавлены подписи четырех типов событий, подписи статусов обучения и формат начала недели `дд.мм`.
2. `ActivityChart` отображает недели в полученном порядке: высота относительно максимума, минимум 4% для ненулевого значения, числа и даты текстом, список с доступным названием. При всех нулевых счетчиках выводится только пустое состояние.
3. `ActivityFeed` отображает упорядоченный список событий, подпись действия, название урока либо курса либо «—», дату и время. Названия без ссылок, порядок сервера сохранен.
4. График подключен в профиль, лента — в карточку статистики пользователя; заголовки и окружающие секции сохранены.
5. Фильтр «Статус обучения» строится из `LEARNING_STATUSES` и типизированной карты подписей. Статус включен в URL, `hasFilter` и сброс всех трех фильтров.
6. Добавлены три теста `ProtectedRoute`: анонимный пользователь видит вход, студент — отказ, администратор — защищенное содержимое. Каждый тест создает свой store и проверяет один экран; пользователи созданы через `publicUserSchema.parse`.
7. Добавлены проверки кругового преобразования URL для всех трех статусов и сброса к общим значениям по умолчанию при неверном статусе с другими фильтрами.

Хотя бы один столбец ненулевой; пустое состояние отсутствует. Числа читаются независимо от высоты и цвета столбцов.
