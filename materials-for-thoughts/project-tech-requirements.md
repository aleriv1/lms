**Frontend-часть**

1.  Вывод списка элементов;
2.  Форма отправки;
3.  Страницы (вкл. страницы одного элемента и приватные страницы);
4.  Использование библиотеки для управления состоянием;
5.  Редактирование элементов; 
6.  Удаление элементов;
7.  Кастомные хуки (желательно); 
8.  Loader;
9.  Базовые компоненты (например, поле ввода).

**Backend-часть**

1.  Node.js
2.  Использование Express.js;
3.  MongoDB
4.  Все виды запросов (CRUD-операции);
5.  Использование промежуточных обработчиков (middleware);
6.  Модели mongoose;
7.  Вход и регистрация.
